リサーチャー
Researcher
市場調査

「まだ存在しないアプリ」を発掘する調査専門家。SNS・フォーラム・App Storeを横断して分析。

プランナー
Planner
企画・設計

要件ヒアリングから基本設計・詳細設計まで担当。ゲーム企画では仕様書の保存とコードスケルトン生成まで行う、チームの起点となる司令塔。

グラフィックデザイナー
Graphic Designer
グラフィック

外部ツールやフリー素材を活用してゲーム・UIのビジュアルアセットを制作し、Code Generatorへ渡す。

ミュージックジェネレーター
Music Generator
音楽・SE

BGM・SE・ジングルを無料素材またはWeb Audio APIで制作。ゲームに音の命を吹き込む音楽担当。

コードジェネレーター
Code Generator
実装

仕様書をもとにHTML/CSS/JSを実装。グラフィックと音楽の納品物も組み込む。大規模タスクは並行分割で対応。

QUALITY GATES品質ゲートDynamic Tester の前に3体を並列実行し、通過して初めて採点へ

リーガルチェッカー
Legal Checker
法務チェック

著作権・ライセンス・利用規約の法務リスクを検査。RED/YELLOW/GREENの3段階で判定・報告する。

セキュリティ
Security
セキュリティ

XSS・SQLインジェクション・SRI未設定などの脆弱性を検査し、修正案を提示する必須品質ゲート。CRITICALが残る間は先へ進ませない。

多言語対応
i18n
日英バイリンガル

日英バイリンガル表記の漏れを検出し、用語を統一して対訳を適用。サイト全体の言語品質を守る必須品質ゲート。

アセット番人
Asset Guardian
アセット方針

WebP方針・解像度・アルファ・参照整合・容量を機械検査で守る必須品質ゲート。404もエラーも出さずに絵が消える事故を止める。

ダイナミックテスター
Dynamic Tester
動的テスト

Playwright（ヘッドレスChromium）でHTMLを実際に起動。JSランタイムエラー・Canvas描画・404アセットを動的に検証する必須品質ゲート。

エバリュエーター
Evaluator
検証・採点

成果物を100点満点で採点。合格基準80点以上を厳格に判定し、品質を保証してGitHubへプッシュする。単発依頼ではバグ・コード品質の診断レポートも出す。

RELEASEリリース合格した成果物を公開し、世に届ける

リリース
Release
リリース

Evaluator合格後の公開担当。kai_001→mainのマージ・バージョンタグ付け・CHANGELOG生成・GitHub Pages疎通確認まで。

マーケター
Marketer
マーケティング

完成成果物の市場投入を担う。競合調査・ターゲット分析・KPI設定からX投稿・PR文・キャッチコピーの生成まで一貫対応。

POST-RELEASE LOOP公開後の改善ループ起動条件を満たしたとき個別に動き、変更後は必ず回帰確認へ

オプティマイザー
Optimizer
性能改善

静的解析でパフォーマンスのボトルネックを特定。FPS改善・メモリリーク修正・Canvas描画最適化を担当する。

リファクタリング
Refactoring
コード整理

外部の挙動を変えずに内部構造だけを改善。重複コードの統合・共通ユーティリティ抽出・責務分離で技術的負債を返す。

ゲームバランス
Game Balance
バランス調整

ゲームのパラメータ定数を抽出して難易度曲線を分析。深澤の承認後にパラメータのみを調整する。

アチーブメント
Achievement Agent
実績称号

ゲームメカニクスを読み解き、ユニークでユーモラスな実績称号を20個生成するムードメーカー。

STANDALONE単独起動開発パイプラインとは独立して動く

切り分け
Triage
不具合の診断

「動かない」という報告から再現手順と観測事実を作り、壊れている層を1つに絞って担当へ渡す。直さないことが仕事。

検査職人
Verifier
機械検査の作成

二度踏んだ「例外もエラーも出ない不具合」を verify スクリプトへ昇格させる。故障を仕込んで✗が出るまで納品しない。

英語講師
English Teacher
英語学習

深澤の英語学習を支援する単独ユーティリティ。会話練習・英作文添削・文法解説・発音指導をCEFR基準のレベルで行う。
