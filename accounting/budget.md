# 予算設定（Budget）

経理エージェント（`.claude/agents/accounting-agent.md`）が参照する予算定義。
**この値は機械可読**。`KEY: VALUE` 形式を崩さないこと（hookがパースする）。

```
CURRENCY: JPY
MONTHLY_LIMIT: 5000
ALERT_THRESHOLD_NOTICE: 70
ALERT_THRESHOLD_WARN: 90
ALERT_THRESHOLD_STOP: 100
RESET_DAY: 1
ZERO1_API_LIMIT: 3000
```

## 説明
| 項目 | 値 | 意味 |
|---|---|---|
| `CURRENCY` | JPY | 通貨（日本円） |
| `MONTHLY_LIMIT` | 5000 | 月次の課金累計上限（¥5,000） |
| `ALERT_THRESHOLD_NOTICE` | 70% | 🟡 注意通知の閾値（¥3,500） |
| `ALERT_THRESHOLD_WARN` | 90% | 🟠 警告通知の閾値（¥4,500） |
| `ALERT_THRESHOLD_STOP` | 100% | 🔴 停止＆要承認の閾値（¥5,000超） |
| `RESET_DAY` | 1 | 毎月この日に累計をリセット（月初） |
| `ZERO1_API_LIMIT` | 3000 | ZERO-1 のクラウドLLM利用の上限（¥3,000）。**`MONTHLY_LIMIT` の内数**（別枠ではない） |

## ZERO-1 のクラウドLLM枠（2026-09-06 深澤承認）

課金ゼロの唯一の例外。**ZERO-1（`zero-1-local-ai`）のクラウドLLM呼び出しに限り**、
月 ¥3,000 まで認める。上限は全体の ¥5,000 の内数なので、合計は増えない。

- **他の用途へは使わない**。この枠はZERO-1の推論だけのもので、画像生成・音声・ストック素材等は
  従来どおり課金ゼロ（`ALERT_THRESHOLD_STOP` の対象）
- **上限は仕組みで守る**。「気をつける」では守れないので二重にする:
  ① 提供元の管理画面でハード上限を設定する（人が設定する。ここは自動化しない）
  ② ZERO-1 自身が呼ぶ前に当月消費を見て止める（`app/api-budget.ts`）
- **鍵はサーバ側だけ**。`.env.local`（gitignore済み）に置き、クライアントコードへは出さない。
  出すとページを開いた相手が鍵を読める（ZERO-1 は 127.0.0.1 に閉じているが、鍵は別の話）
- **単価が分からないモデルは呼ばない**。価格表に無いモデルは「いくらかかるか分からない」ので
  止める（推測で見積もると、上限が上限でなくなる）

## 大前提
- プロジェクト方針は **課金ゼロの維持**（CLAUDE.md「APIキーに関する禁止事項」/ music-generator.md L28-35）。
  唯一の例外が上の ZERO-1 枠（¥3,000・深澤承認）。
- 上限¥5,000は「**万一の例外的課金に対する安全装置**」であり、通常運用での消費を想定したものではない。
- 上限の変更は深澤（PM）の明示的な指示があった場合のみ行う。
