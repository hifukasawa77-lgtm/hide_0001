# 0034: 全エージェントに「契約・最小権限・必須検査」を導入し、規約を検査#14で強制する

## 背景
深澤から「全AIエージェントの大幅なブラッシュアップがしたい」。19体を読み直したところ、
0028で解消した「孤立」とは別種の穴が3つ残っていた。

1. **権限が全開だった** — `tools:` を持つのは19体中3体だけ。「i18nはデザインを変えない」
   「Evaluatorは採点者」と**文章で**書いてあっても、全ツールが付いていれば長い作業の途中で必ず破られる。
2. **CLAUDE.mdの検査カタログがどのエージェントにも紐付いていなかった** — `verify-*.mjs` 22本を
   参照するエージェント定義は実質ゼロ（marketer 2件・game-balance 1件のみ）。
   「完成の定義」が各エージェントの主観に委ねられ、**このリポジトリ特有の無言バグ**
   （絵が消える／肖像がずれる／0%で止まる）を通す道が開いたままだった。
3. **受け渡しが定型でなかった** — 「受け取る情報」「入力」「ハンドオフ」の書式が各自バラバラで、
   上流の不足に気づかず推測で着手できてしまう。

加えて、法務チェックで改称した `game.html` → `zelda_like.html` が **6ファイルで旧名のまま**残り、
`security.md` は「zelda_like.html が JSX を Babel でトランスパイルする」という**現存しない構成**を
説明していた（改称前から既に古かった記述が、改称でさらにずれた）。

## 決定
1. **共通運用規約を `.claude/agent-conventions.md` に一本化**（契約書式／最小権限の原則／
   コンテキスト節約／**必須検査の対応表**／停止条件・エスカレーション／振り分け表）。
   各定義は「自分の専門」だけを書き、共通事項を重複させない。
   ※ `.claude/agents/` の外に置く（中に置くとエージェント定義として走査され、検査#13が誤検知する）。
2. **全22体に `tools:` を宣言**。診断・監査系（security / legal-checker / evaluator / dynamic-tester /
   triage）から **Edit・Writeを外す** — 「検査する者が対象を書き換えない」。
   MCPコネクタが要る2体（graphic-designer / pmo）だけ絞らず、理由を本文に明記する。
3. **契約（受け取る／返す／次の担当）と停止条件を全体へ**。旧「入力」「受け取る情報」節は削除（重複を残さない）。
4. **新設3体** — `asset-guardian`（品質ゲート4体目。WebP方針・参照整合・容量）／
   `triage`（症状→再現→層の切り分け。直さない）／`verifier`（無言バグを機械検査へ昇格）。
5. **harness-lint 検査#14** で規約適合を機械検査する（tools宣言・契約/停止条件の有無・
   参照する検査スクリプトとページの実在）。

## 理由
- 0007以降の一貫した方針＝**「方針は検査で守る」**。規約を書くだけでは 0028 と同じ形で腐る。
  実際に検査#14は導入直後に2件（legal-checkerの旧ページ名参照・規約内のプレースホルダ）を捕まえた。
- **権限で表現できる制約は権限で表現する**。文章の禁止事項は破られても検知できないが、
  ツールが無ければ物理的に起きない。
- **triage を独立させた理由**は「切り分けながら直すと、何が効いたのか永久に分からなくなる」から。
  2026-08-02 の `_drawRoads` 誤診（「アセット読込が重い」「roundRect非対応」と誤診して3コミット）は、
  再現と観測を分離していれば1コミットで済んでいた。

## 結果
- エージェント 19体 → **22体**。品質ゲートは3体並列 → **4体並列**。
- CLAUDE.md・`agents.html`（カード／フロー図／バーチャルオフィスの席）・note記事・SNS文面・
  Instagram画像の「19体」を **22体**へ同期（`verify-note-articles` の検査#9が食い違いを検知した）。
- 故障注入で検査#14が ✗ を出すことを確認済み（tools削除／契約節の削除／存在しないスクリプト参照）。

## 学び
- **「〜しない」と書いた責務は、ツールを外して初めて守られる**。
- **数字を書いた文書は、機械検査が無ければ黙って嘘になる**。今回もエージェント数の変更で
  note記事・SNS投稿・生成画像が一斉に古くなり、検査だけがそれを見つけた。
