6502 CPU ミニコア

NROM 系の起動に必要な命令から段階的に増やすための、命令ステップ実行デモです。

実装ロードマップ / Implementation roadmap

1. CPU Bus

6502 全命令、割り込み、NMI/IRQ、DMA、NROM/UNROM/MMC1/MMC3。

2. PPU

背景・スプライト・スクロール・ミラーリング・スプライト0ヒットを scanline 単位で再現。

3. APU

矩形波、三角波、ノイズ、DMC を AudioWorklet へ接続。

4. Input

キーボード/ゲームパッド、セーブステート、巻き戻しの基盤。

5. FDS

BIOS 読込、2C33 レジスタ、IRQ タイマ、ディスク面切替、FDS 音源。

6. Compatibility

テスト ROM、ログ比較、フレームタイミング調整で互換性を上げる。

注意: 市販ゲームの ROM や FDS BIOS は同梱しません。ユーザー自身が権利を持つデータをローカルで読み込む設計です。
