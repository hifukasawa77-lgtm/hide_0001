Privacy Policy — what this site does (and doesn't) send outside your browser

更新日 / Last updated: 2026-09-07

1. 基本方針 Basic policy

本サイト「hideの部屋」は GitHub Pages 上でホスティングされた静的サイトで、個人のサーバーを持ちません。ゲームの進行状況・設定・会話履歴などのほとんどの機能は、お使いのブラウザの localStorage にのみ保存され、外部へ送信されることはありません。

This site, "hide's Room," is a static site hosted on GitHub Pages and does not run its own backend server. Most features — game progress, settings, chat history, and so on — are stored only in your browser's localStorage and are never transmitted externally.

Cloud Brain 2. ZERO-1 Mobile の「クラウド頭脳 / Cloud Brain」について About ZERO-1 Mobile's Cloud Brain

zero-1-mobile.html（ZERO-1 Mobile）には、「クラウド頭脳 / Cloud Brain」という任意のオプトイン機能があります。既定は必ずOFFで、利用者が明示的に有効化しない限り、外部への送信は一切発生しません。

この機能をONにして、ご自身のOpenAI APIキー（BYOK: Bring Your Own Key）を設定した場合に限り、以後の会話内容が OpenAI, Inc. の提供するAPI（api.openai.com）へ送信されます。

  • 送信は利用者の端末（ブラウザ）から OpenAI へ直接行われます。本サイトの運営者（hide）は、このAPIキーも会話内容も一切収集・保持・閲覧しません。運営者が用意したサーバーを経由することもありません。 The request goes directly from your device (browser) to OpenAI. The site operator (hide) never collects, stores, or views your API key or conversation content, and no operator-run server sits in between.
  • APIキーはブラウザの localStorage にのみ保存され、送信先は CSP（Content-Security-Policy）の connect-src で api.openai.com 等に限定されています。 Your API key is stored only in your browser's localStorage. The page's CSP restricts connect-src so requests can only go to the allow-listed destinations, including api.openai.com.
  • この機能の利用で発生する課金は、利用者ご自身のOpenAIアカウントに対して発生します。本サイト運営者への課金は一切発生しません。 Any usage charges from this feature are billed to your own OpenAI account. The site operator is never billed.
  • OpenAIへ送信されたデータの取り扱いは OpenAI 社のプライバシーポリシー（外部サイト）に従います。OpenAI Privacy Policy ↗ Data sent to OpenAI is handled under OpenAI's own privacy policy (external site).

案内エージェント 3. サイト内チャット（案内エージェント）について About the site guide chat agent

サイト右下に表示される案内エージェント（チャットウィジェット）は、入力された質問を本サイト運営者が管理する Cloudflare Worker を経由して Cloudflare Workers AI（Gemma / Llama系モデル）へ送信し、回答を生成します。ログイン・アカウント登録は不要で、氏名やメールアドレス等の入力を求めることもありません。回答精度の改善のため、匿名化された質問・回答の一部を共有の学習メモリへ一時的に保存する場合がありますが、個人を特定できる情報は含みません。

The site's chat widget (bottom-right) sends what you type to a Cloudflare Worker managed by the site operator, which relays it to Cloudflare Workers AI (Gemma/Llama-family models) to generate a reply. No login or account is required, and you are never asked for your name or email address. To improve future answers, an anonymized subset of question/answer pairs may be cached in a shared learning store, but it does not include personally identifying information.

4. その他の外部連携（任意機能） Other external integrations (opt-in)

一部のページ（例: ダッシュボードのGoogleカレンダー連携）では、利用者ご自身の操作でGoogle等の外部サービスと連携する機能があります。連携するかどうかは利用者の選択に委ねられ、連携しない限り外部へのデータ送信は発生しません。また、フォントやCDN配信のJavaScriptライブラリなど一部の静的アセットは外部サーバーから読み込まれますが、これらの読み込みに会話内容や個人情報が含まれることはありません。

Some pages (for example, the dashboard's Google Calendar integration) offer optional connections to external services like Google, initiated only by your own action. Nothing is sent unless you choose to connect. A few static assets (web fonts, CDN-hosted JavaScript libraries) are also loaded from external servers, but these requests never include your conversation content or personal data.

トップページの「ダッシュボード」を開き、ブラウザの位置情報許可を与えた場合のみ、緯度・経度が天気・雨雲レーダー・大気質の各カードの取得先（国土地理院の逆ジオコーダー、Open-Meteo、ウェザーニュース、Windyの雨雲レーダー表示）へ送信されます。許可しなければ位置情報は一切送信されません。

If you open the "Dashboard" on the top page and grant browser location permission, your latitude/longitude is sent to the services behind the weather, rain-radar, and air-quality cards (Geospatial Information Authority of Japan's reverse geocoder, Open-Meteo, Weathernews, and Windy's rain radar embed). Nothing is sent unless you grant permission.

5. アクセス解析・広告 Analytics & advertising

本サイトは、第三者によるアクセス解析タグ・広告トラッキングを設置していません（本ページ更新時点）。

This site does not embed any third-party analytics or ad-tracking tags (as of this page's last update).
