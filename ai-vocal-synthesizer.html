🔬 このツールの仕組み How it works

歌声合成 / Singing synthesis：声帯波（グロッタルパルス）を合成した音源に、母音ごとの 4つのフォルマント（共鳴）帯域フィルタを並列にかけるソースフィルタ方式です。子音は破裂・摩擦・鼻音・わたり音の 4タイプをノイズと調音遷移で作り分け、母音への渡りでフォルマントを補間しています。
A source–filter model: a synthesized glottal pulse train is shaped by four parallel band-pass formant filters per vowel, with plosive / fricative / nasal / glide consonants and formant transitions.

自動作曲 / Auto-composition：コード進行（王道進行・カノン進行など）を土台に、 歌詞のモーラ数からリズムを決め、強拍でコードトーンを優先する重み付き確率モデルで音高を選びます。 フレーズ終わりは主音へ解決します。シードで再現可能です。
A seeded probabilistic model over chord progressions: rhythm from the mora count, pitches weighted toward chord tones on strong beats, cadencing to the tonic.

メロディ採譜 / Transcription：取り込んだ音声を16kHzモノラルに落とし、 YIN法（差分関数の累積平均正規化）でフレームごとの基本周波数を求めます。オクターブ飛びを補正して 中央値で平滑化し、音高の変化・無音・子音のアタック（高域エネルギーの立ち上がり）を手がかりに音符へ切り分け、 音符の開始時刻からテンポを、音高のヒストグラムからキーを推定して16分音符グリッドへ量子化します。
YIN pitch tracking with octave correction and median smoothing; notes are segmented by pitch change, silence and high-frequency onsets, then quantized against an estimated tempo and key.

プライバシー / Privacy：歌詞も音声もすべて端末内で処理され、外部送信は一切ありません。 Everything runs locally; nothing is uploaded.
Vanilla JS + Web Audio API / Canvas API — フレームワーク不使用・外部通信なし。WAVは 44.1kHz 16bit ステレオで書き出します。
デモの「かえるのうた」はパブリックドメインの旋律（冒頭2フレーズ）です / The bundled folk melody is public domain.
音声の取り込みには https（GitHub Pages）または localhost が必要です。取り込んだ音源の権利にはご注意ください / Audio capture requires a secure context; mind the rights of any audio you import.
