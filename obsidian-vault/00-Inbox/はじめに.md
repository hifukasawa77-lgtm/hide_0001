# 00-Inbox — スマホから投げ込む場所

このフォルダは**深澤がスマホのObsidianから書いたメモの着地点**です。整理しなくてよい。
思いついた順に書き捨てて構いません。

## Claude Code 側の約束
- セッション開始時、`.claude/hooks/second-brain-recall.sh` が **このフォルダのメモを全文読み込む**
  （`MOC.md`・知見インデックス・直近Dailyに加えて）。だから**書けば必ず次のセッションで届く**
- Claude はメモを読んだら、行き先のあるものを振り分ける:
  - 意思決定 → `03-Decisions/`（ADR）
  - 再利用できる学び → `04-Knowledge/`
  - プロジェクトの状態 → `02-Projects/`
  - その日の作業記録 → `01-Daily/`
- 振り分けたらこのフォルダから消す（残したままだと毎セッション読み直して文脈を食う）
- **勝手に消さない**: 行き先が決まらないメモはここに残し、深澤へ「どこへ入れますか」と聞く

## 書き方
形式は自由。日付も見出しも要りません。1行でも構いません。
迷ったら「いつ・何を・なぜ」だけ入れてくれると、ADR へ昇格させやすくなります。
